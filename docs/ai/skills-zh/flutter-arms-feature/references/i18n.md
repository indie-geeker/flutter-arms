# 基于 slang 的 i18n

## 工作流

1. 同时编辑 `lib/i18n/en.i18n.json` 和 `lib/i18n/zh.i18n.json`。保持结构对称——一方加了 key，另一方也要加。
2. 运行 `dart run slang`（或 `tool/gen.sh`）以重新生成 `strings.g.dart`。
3. 在 widget 里通过 `context.t.<path>` 访问：

   ```dart
   Text(context.t.auth.welcomeBack);
   ```

`context.t` 是 slang 生成的扩展，会返回当前 locale 的字符串。无需 `AppLocalizations` 的 BuildContext 查询。

## 新增 feature 命名空间

两份文件要保持同形。各自追加：

```json
{
  "auth": { /* ... */ },
  "settings": {
    "title": "Settings",
    "notifications": "Notifications",
    "language": "Language"
  }
}
```

然后 `context.t.settings.title`。

## 动态参数

slang 用 `{paramName}` 作为占位：

```json
{
  "greeting": "Hello, {name}!",
  "itemCount": "{count, plural, =0{No items} =1{1 item} other{{count} items}}"
}
```

Dart 里：

```dart
Text(context.t.greeting(name: user.name));
Text(context.t.itemCount(count: items.length));
```

## `errors` 命名空间（关键）

每个 `FailureCode` 值都**必须**有对应 `errors.<code>` key：

```json
{
  "errors": {
    "network": "Network connection failed",
    "timeout": "Request timed out",
    "badResponse": "Server error",
    "auth": "Session expired, please sign in again",
    "validation": "Invalid input",
    "cancelled": "Request cancelled",
    "unknown": "Something went wrong"
  }
}
```

`context.failureMessage(failure)` 使用它：

- `badResponse` 和 `validation` → 先尝试 `failure.detail`（服务端消息或校验提示），为 null 时回退 `t.errors.<code>`。
- 其它 → 始终 `t.errors.<code>`。

新增 `FailureCode` 时，同时在两份 JSON 加对应 key，并更新 `context.failureMessage` 的 switch（`lib/core/extensions/build_context_ext.dart`）。

## 在 Notifier 中访问当前 locale

```dart
final currentLocale = ref.watch(localeProvider);  // AppLocale 枚举
```

`localeProvider` 在 `lib/core/locale/locale_notifier.dart`。切换：`ref.read(localeProvider.notifier).setLocale(AppLocale.zh)`。

## 避免清单

- `AppLocalizations.of(context)` —— 本项目用 slang，不用 intl 生成。没有 ARB 文件。
- Dart 里硬编码面向用户的字符串。看到 widget 里有字面量就把它移到两份 JSON 并重新生成。
- JSON 不对称 —— 在 `en.i18n.json` 加了 key 但漏了 `zh.i18n.json`（反之亦然），slang 代码生成会抛错。
- 用陈旧的 `t.path`（`t` 已过期）—— 始终在 `build()` 内部通过 `context.t` 访问，locale 变化才能正确重绘。
